# MT5 Strategy Tester EA

This folder contains the MT5-side research expert used by `/api/mt5/tester/run`.

## File

- `Experts/QuantForexV10_ResearchEA.mq5`

## Setup

1. Open MetaEditor.
2. Copy `Experts/QuantForexV10_ResearchEA.mq5` into your terminal data folder under `MQL5/Experts/`.
3. Compile it to create `QuantForexV10_ResearchEA.ex5`.
4. Set `MT5_TERMINAL_PATH` or `MT5_PATH` in `.env` to your `terminal64.exe` path.
5. Use the app's `MT5 Strategy Tester Automation` panel.

The EA is tester-only by default. It returns `INIT_FAILED` outside Strategy Tester unless `AllowNonTesterExecution=true` and the explicit safety confirmation token is also supplied.

## Safety

Default behavior is Strategy Tester only:

```text
AllowNonTesterExecution=false
```

If the EA is attached outside Strategy Tester, it blocks during `OnInit`.

For controlled demo-only experiments outside Strategy Tester, two inputs are required:

```text
AllowNonTesterExecution=true
NonTesterSafetyConfirm=I_UNDERSTAND_THIS_CAN_TRADE_LIVE
```

When this override is enabled, the EA shows a danger alert because it can send demo/live orders. Do not use the override on funded or live accounts.

## What It Executes

The EA reads the `.set` file generated by the backend:

- regime and strategy filters
- risk, RR, and date range
- strict filter controls
- ICT/FVG/OB/BOS/MSS/liquidity/VWAP/MVWAP/session VWAP switches
- alpha and pattern score thresholds
- optional Python source-of-truth signal CSV

Preferred validation mode is Python signal source-of-truth:

```text
UsePythonSignalCsv=true
PythonSignalCsvFile=QuantForexV10_python_signals_<run_id>.csv
RequirePythonSignalCsv=true
```

In that mode the Python backend builds the exact regime/strategy/pattern/filter signals, writes a CSV with `PYIDX` and `PYHASH`, and the EA executes only those rows in MT5 Strategy Tester. This avoids drift between the full Python 40-regime engine and the simplified MQL detector.

It tags comments as:

```text
R36|VW1|PYIDX:12|PYHASH:abc123...
```

It also writes a common-files signal log named:

```text
QuantForexV10_ResearchEA_signals.csv
```

The Python app can still import normal MT5 tester reports through the existing report importer.

If `UsePythonSignalCsv=false`, the EA falls back to its internal MQL detector. That fallback is useful for smoke tests, but it is not the institutional parity path because the full Python backend remains the source of truth.
